# 🤖 TechCode - Plataforma de Cursos de Tecnologia

Site institucional desenvolvido para a Atividade 06 da disciplina de Programação de Computadores (PCII) da **Etec Alberto Santos Dumont**. 

A **TechCode** é uma plataforma fictícia voltada para o ensino de tecnologia de forma intuitiva, prática e divertida para jovens e iniciantes.

---

## 🚀 Tecnologias Utilizadas
* **HTML5** (Estruturação das páginas)
* **CSS3** (Estilização e design responsivo)

---

## 📄 Estrutura de Páginas do Projeto
O site é composto pelas seguintes páginas completas:
* `index.html` - **Home:** Página principal com chamada para ação dos cursos.
* `servicos.html` - **Serviços:** Trilhas de aprendizado (Desenvolvimento Web, Lógica de Programação e Projetos Práticos).
* `parceiros.html` - **Parceiros:** Empresas e instituições apoiadoras.
* `FAQ.html` - **FAQ:** Perguntas frequentes com campo de busca.
* `blog.html` - **Blog:** Artigos e dicas de tecnologia para iniciantes.
* `contato.html` - **Contato:** Formulário de atendimento ao usuário ("Fale Conosco").
* `sobre.html` - **Sobre Nós:** Missão, visão e valores da TechCode.

---

## 💻 Como Executar o Projeto Localmente
1. Baixe ou clone este repositório em sua máquina.
2. Abra a pasta do projeto.
3. Dê um duplo clique no arquivo **`index.html`** para abrir o site diretamente no seu navegador web favorito.
